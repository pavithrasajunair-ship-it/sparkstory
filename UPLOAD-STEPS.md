# Upload to GitHub (about 3 minutes, no coding)

1. Unzip this folder on your computer.
2. Open  https://github.com/pavithrasajunair-ship-it/sparkstory
3. Click  Add file  >  Upload files.
4. Open the unzipped folder and select EVERYTHING inside it (including the "icons" folder), then drag it into the GitHub page.
   Files that already exist (index.html, sw.js, vercel.json) are replaced by the new ones.
5. Scroll down, type a message such as  "Add look, music and offline install", and click  Commit changes.
6. Wait about a minute. Vercel publishes it by itself.
7. Open  https://sparkstory.vercel.app/  and press Ctrl+Shift+R (or reload twice on a phone) to load the new version.

If you changed index.html on GitHub after I read it today, tell me first so I can merge instead of replacing.
